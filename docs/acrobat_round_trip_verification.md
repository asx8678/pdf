## What is verified automatically

The automated leg (author here → save → re-open here → re-read) is exercised for
every annotation kind by
[`test/quire/annotations/round_trip_test.exs`](../test/quire/annotations/round_trip_test.exs),
against fixtures generated by
[`scripts/generate_annotation_fixtures.mjs`](../scripts/generate_annotation_fixtures.mjs).
It asserts each annotation retains its **kind, geometry (PDF points), colour,
opacity, author, contents** through the save/re-open round trip, including the
corpus-geometry fixtures `rotated_annotated.pdf` and
`cropped_origin_annotated.pdf` (rotated page + cropped non-zero origin).

## How to run the manual Acrobat pass

Acrobat is **not installed on this machine** `(/Applications`), so the manual
pass cannot be executed here. Run it on a host with Acrobat (Adobe Acrobat Pro):

1. `make fixtures` (or `node scripts/generate_annotation_fixtures.mjs`).
2. Open **each** file in `test/fixtures/annotations/*.pdf` in Acrobat and confirm
   the annotation is visible and interactive.
3. Save each file from Acrobat (File → Save As…, keep PDF), then re-open the
   saved file **in this app** and confirm the annotation still round-trips
   losslessly (`mix test test/quire/annotations/round_trip_test.exs` after placing
   the Acrobat-saved files back into the fixtures dir, or via the round-trip
   acceptance in the UI).
